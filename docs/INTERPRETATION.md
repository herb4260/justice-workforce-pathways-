# Interpretation guide

## What the project demonstrates
- How organizational-justice theory can be embedded in police-training evaluation.
- How to separate training **motivation**, **receptivity**, and **later transfer** rather than collapsing them into one outcome.
- How to test heterogeneity instead of assuming one average effect applies equally to everyone.
- How to combine randomized/cohort assignment logic, longitudinal repeated measures, administrative context, scenario outcomes, and implementation interviews.
- How to diagnose whether poor outcomes are diffuse or concentrated before proposing an intervention.
- How to build automated checks so an apparently successful analysis cannot silently rely on implausible synthetic data or unstable model estimates.

## What the project does not demonstrate
It does not establish the efficacy of real behavioral-health training, estimate real gender differences, measure real organizational justice, or make claims about Korean or U.S. police agencies. All numerical results are properties of a simulation designed to exercise an analytic workflow.
