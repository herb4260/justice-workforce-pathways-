# Interpretation guide

## What this project can show
- How to structure a longitudinal workforce dataset.
- How to distinguish acute and chronic occupational exposures.
- How to estimate repeated-measures and clustered models.
- How to link self-report, administrative, and qualitative evidence.
- How to build automated diagnostics that fail when synthetic data become implausible.

## What it cannot show
It cannot estimate prevalence, causal effects, treatment effects, suicide risk, or organizational performance in any real justice agency. All apparent effects are properties of the simulation.
