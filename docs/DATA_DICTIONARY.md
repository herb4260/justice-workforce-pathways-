# Data dictionary

| Variable | Meaning |
|---|---|
| `person_id` | Synthetic participant identifier |
| `facility_id` | Synthetic facility/unit identifier |
| `wave` | 1, 2, 3, or 4 |
| `months` | 0, 12, 24, 36 |
| `acute_exposure` | Critical-incident exposure index |
| `org_stress` | Chronic organizational/operational stress, 1–7 |
| `supervisor_support` | Perceived supervisor support, 1–7 |
| `peer_support` | Perceived peer support, 1–7 |
| `stigma` | Help-seeking stigma, 1–7 |
| `distress` | General psychological distress, 1–7 |
| `burnout` | Occupational burnout, 1–7 |
| `ptsd` | PTSD-symptom proxy score, 1–7 |
| `suicidal_ideation` | Synthetic binary ideation indicator |
| `help_seeking` | Synthetic binary formal help-seeking indicator |
| `overtime_hours` | Administrative overtime hours in interval |
| `sick_days` | Administrative sick-leave days in interval |
| `critical_incidents` | Administrative critical-incident count |
| `turnover_event` | 1 when synthetic participant exits workforce |
